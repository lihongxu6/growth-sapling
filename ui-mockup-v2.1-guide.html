设计师说明 · v2.1 用户引导功能（Coach-mark 实测定位版）

一、本次重写纠正了什么

  • 不再凭想象填坐标：上一版直接手写像素值，未读真实页面 CSS，导致气泡远离操作点。本版用 getBoundingClientRect() 在渲染后实测真实元素矩形，气泡自动贴附目标、自动避开画布溢出。
  • 背景严格复刻线上：三页背景直接映射 tasks/home/stats.wxss 的 token（calc(1 * var(--u)) = 393/750 ≈ 0.524px），保证操作点位置与真机一致。
  • 单只松鼠：全稿只有气泡内这只果果头像（真实 IP 资产 avatar-144-transparent.png），文案内与操作手册卡片内均不再出现第二只 🐿️。
  • 跳过 / 关闭 / 下一步与文案同区：都在气泡卡内，不放页面顶部，视线不上下跳。
  • 「跳过」降权为小 ×（G3–G5 概念步）：无「跳过」文字、仅 22×22 半透明灰 ×，鼠标悬停加深；语义 = 关闭整个引导（非「下一步」等价）。G1/G2 强制操作步无跳过按钮（必须真点目标，不可跳）；G6 末步无跳过（最后一步无可跳，仅「完成」）。

二、6 步引导 + 操作手册（与 §3.29/§3.30/§3.38 锁定一致）

  • G1 添加任务（任务页·真实）· G2 今日打卡（打卡页·真实）· G3 看日历（成长页月历）· G4 看徽章（成长页徽章墙）· G5 改头像（成长页头像）· G6 操作手册入口（成长页底部小文字链接）。
  • G1/G2 为真实逐步引导（孩子真点添加/打勾）；G3–G6 为概念性看图，不强求操作。
  • G7 操作手册弹层（v2.1 新增）：点 G6 的小链接后从底部滑出。内容 = 把 6 步引导脱壳成干净卡片（添加任务 / 今日打卡 / 看日历 / 看徽章 / 改头像），去掉遮罩、聚焦环、跳过与下一步；底部「再走一遍引导」可重播引导。
  • 入口刻意做小（成长页底部单行文末链接、无「新增」角标、不在 TabBar 加项），避免分散孩子注意力——与 §3.38 设计倾向一致并已落地。

三、待你确认

  • G1 是否要进一步展示「添加弹层 + 预填示例」（§3.33）？当前聚焦在添加按钮本身以直接回应"松鼠挡住添加按钮"的问题。
  • G6 手册入口 / G7 弹层均为 v2.1 新增（§3.27：线上暂无），本稿已按增量新增呈现，未改动其他统计块。
